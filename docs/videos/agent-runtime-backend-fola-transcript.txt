Today, Web DSH, Web Terminal, and installed managed clients operate in the user's private workspace. DSH chat does not forward work to another client. The deployed Agent tasks page separates runtime from execution backend. Web DSH is the control surface. DSH Python SDK, Claude Code, or Deep Agents runs behind it in the private workspace. Every task requires approval, streams persisted output, supports cancellation, and records interrupted recovery. The SDK uses a private checkpoint and pauses tool interrupts for a second approval. Web Terminal includes kubectl without a token or default kubeconfig, so it grants no cluster access by itself. OpenShell remains disabled until all twenty-five qualification and rollback gates pass. Broker health and authentication are verified; guarded model execution and spoken-content review remain.
