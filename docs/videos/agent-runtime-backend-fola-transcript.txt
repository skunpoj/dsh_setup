Today, Web DSH, Web Terminal, and installed managed clients operate in the user's private workspace. DSH chat, the DSH Python SDK entry point, and Claude Code are separate clients. The ordinary chat prompt does not forward work to another client. The approved target design adds two independent web choices: agent runtime and execution backend. DSH Python SDK supports programmatic workflows; Claude Code supports repository work. The private DSH workspace remains the default backend. OpenShell is optional, disabled, and unavailable until its isolation, rollback, resource, and expiry gates pass. The planned web task form and guarded Claude flow are not deployed yet, so this supplement describes the current boundary and the acceptance work still required.
