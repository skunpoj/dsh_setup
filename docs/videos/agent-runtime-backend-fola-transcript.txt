Today, Web DSH, Web Terminal, and installed managed clients operate in the user's private workspace. DSH chat does not forward work to another client. A reviewed source candidate adds an Agent tasks page with two independent choices: agent runtime and execution backend. It offers DSH Python SDK, Claude Code, and Deep Agents in a confined private project. Every task requires explicit approval, streams persisted output, supports cancellation, and records interrupted recovery. OpenShell is shown but disabled until all isolation, rollback, resource, and expiry gates pass. The candidate is not deployed yet. This lesson becomes current only after immutable build, bounded live acceptance, running-digest verification, and spoken-content review.
