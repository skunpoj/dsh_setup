Main DSH controls and working examples
Main D S H already offers local application ports and approved external H T T P S targets. The visitor access selector offers Require D S H sign in and Public access. Authenticated sharing and destination permissions are separate. RegChat is a configured example, rather than a special login mechanism. Use the Main settings page and the approved application links supplied by your operator. Opening a saved link does not create a mapping, start an application, or change its permissions.

Main and Test application links
Main and Test serve different purposes. The gated and Public RegChat examples are available through Main. App Five and App Six are controlled Test examples. App Five requires a normal D S H session. Sign in through normal D S H, then return to the original application tab. That tab resumes its original application path. App Six uses Public routing, but the destination can still require its own login. Public access does not open a workspace, notebook, terminal, or chat history.
