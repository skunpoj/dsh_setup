Web DSH compared with the Python SDK

Web DSH is the authenticated control surface: it chooses the runtime, project, write mode and execution backend, then displays state and output. The Python SDK is one runtime behind that surface: it creates the programmatic agent, invokes tools, saves its checkpoint and resumes an approved interrupt. Choosing it does not turn ordinary DSH chat into an SDK conversation and does not give the browser a model credential.

Deployed behavior and remaining acceptance boundary

The current gateway and broker are deployed. The reviewed successor adds Kilo, bounded cross-runtime handoff and correlation metadata, and its source tests pass. No successor image, Test deployment or live handoff has yet been verified. Guard-to-LiteLLM reconciliation, TrueForge adapter behavior and OpenShell acceptance remain unverified.
