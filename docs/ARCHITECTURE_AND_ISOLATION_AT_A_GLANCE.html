Current state versus target

On-prem target: DeepSeek through LiteLLM only, fixed 384K context across all supported agents including compaction. Managed-route defaults are source-configured; arbitrary external HTTPS/provider bypass and all override paths remain unqualified. Separate platform profiles and ownership

On-prem multiharness Kubernetes: controlled enterprise execution, managed DeepSeek/LiteLLM route and the 384K-only target. Shared source integration, operational approval and live execution have separate owners. multiharness.cloud: customizable multi-harness arena target. superharness.cloud: bounded-autonomy roadmap target. Cloud preparation, source integration and deployment have separate owners. These domains are not evidence of live public applications.

Cloud deployment is not yet qualified. Preparation can proceed within its approved scope. A verified free-model default remains pending; paid smoke tests do not qualify it. The autonomy roadmap does not permit agents to relax their own authorization, credentials or resource limits.
