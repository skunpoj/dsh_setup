เรียน ทีมผู้ดูแลระบบ GPU

ขอความอนุเคราะห์ตรวจสอบและวางแผนทดสอบการตั้งค่า GPU peer-to-peer ตามรายงานฉบับปรับปรุงครับ

รายงานฉบับเดียวล่าสุด พร้อมผลวัด กราฟ วิธีทดสอบ ค่าปัจจุบัน และขั้นตอนตรวจสอบ/ย้อนกลับ:
https://github.com/skunpoj/dsh_setup/blob/main/docs/gpu-platform/GPU_PLATFORM_REVIEW.pdf

ปัจจุบันใช้ DeepInfer + DSpark ผ่าน LiteLLM โดย DeepInfer เป็น inference engine แยกจาก vLLM ส่วนชื่อ Service เดิมที่มีคำว่า vllm ไม่ได้หมายความว่ารันด้วย vLLM และยังเก็บ SGLang + DSpark ไว้เป็นทางเลือกย้อนกลับ

ค่าที่อ่านได้จากระบบคือ BIOS 3.16 และ IOMMU groups แบบ DMA-FQ ส่วน ACS และตัวเลือก BIOS รายตัวยังต้องให้ผู้ดูแลตรวจยืนยัน จึงขอเริ่มจากการตรวจแบบอ่านอย่างเดียว ก่อนพิจารณาทดลอง iommu=pt ในช่วงเวลาปิดปรับปรุงที่ตกลงร่วมกัน พร้อมทบทวนผลต่อการแยกอุปกรณ์และเตรียม boot entry สำหรับย้อนกลับ ไม่เสนอให้เปลี่ยน ACS/BIOS ทุกตัวพร้อมกัน

หลังเปลี่ยนค่า ต้องตรวจข้อมูลปลายทางของการคัดลอกระหว่าง GPU ทุกทิศทางที่จำเป็น และทดสอบ DeepEP dispatch/combine ให้ผ่านก่อนทดลองเปลี่ยน expert transport จาก NCCL เป็น DeepEP จากนั้นตรวจความถูกต้องของโมเดลและการคืนบริการผ่านเส้นทางผู้ใช้จริง

ค่าประมาณ 76-147 tokens/s สำหรับ W1 หนึ่งคำขอ เป็นผลคำนวณแบบมีเงื่อนไข ไม่ใช่ผลหลังแก้ไขที่วัดแล้ว รายงานแสดงสมมติฐานและค่าที่คำนวณได้ครบ โดยไม่ได้สมมติความเร็วหลายผู้ใช้หรือเวลาคืนระบบขึ้นมาเอง

ตำแหน่ง configuration ทั้งสามชุดและ runbook หลังเปลี่ยนค่า:
https://github.com/skunpoj/dsh_setup/tree/main/gpu-stack/profiles
